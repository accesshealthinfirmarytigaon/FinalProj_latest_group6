About This Report

Project Overview

This web report documents the comprehensive usability evaluation of the Tigaon – Primary Hospital and Clinic Website, our group's midterm prototype developed for the local Tigaon community.

The evaluation was conducted using two established methodologies: Heuristic Evaluation based on Jakob Nielsen's 10 Usability Heuristics, and Usability Testing using the System Usability Scale (SUS) questionnaire with real respondents.

This site serves as a central repository of evidence, presenting our findings, analysis, and actionable recommendations to improve the platform's usability and overall user experience.
